MODEL NOTES

Simulation model and assumptions

Based on the supplied Role-Leasing Agricultural IoT Protocol Project Spec Sheet. The physical mesh and logical hierarchy are independent. Four roles compete at 10 subnet, 3 network, and 1 internetwork scopes.

What is simulated

Seeded placement, neighbor discovery, join messages, capability aggregation, routed control exchanges, grants and renewals, epoch/version fencing, a two-tick detection delay, a six-message handover, node joins, and sensor load.

Intentional simplifications

One local event loop represents the network. Delivery is deterministic when a route exists; there is no radio contention, retransmission, consensus, or hardware validation. Health, battery drain, and message energy are illustrative. A container uses its first available descendant as a physical representative. This teaching model is separate from the existing Python experiment engine and its stored study results.

Optional migrations require a strict improvement after migration cost and hysteresis. Emergency recovery bypasses that switching threshold. Same-epoch duplicates and stale-epoch grants are rejected in the modeled receiver state.
